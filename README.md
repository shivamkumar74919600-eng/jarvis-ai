# JARVIS AI Personal Assistant (Android Native App)

Yeh aapka complete **Android Studio Project** hai jo:
1. **Aapki aawaaz sunta hai aur bolkar jawab deta hai** (SpeechRecognizer + TextToSpeech in Hindi/English).
2. **WhatsApp message automatically bhejta hai** (Deep Accessibility Service integration).
3. **Reports manage karta hai** (Create, view, manage reports).
4. **Phone hardware control karta hai** (Battery level, torch/flashlight, system volume, app opening, calls).

---

## APK Kaise Banayein (1-Click Steps):

1. Is ZIP file ko extract/unzip karein apne computer par.
2. **Android Studio** open karein aur **"Open"** par click karke is `JarvisAndroidProject` folder ko select karein.
3. Android Studio dependencies sync karega (1-2 minutes).
4. Top menu mein jayein:
   - **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)**.
5. Android Studio kuch seconds mein aapka **`app-debug.apk`** generate kar dega!
6. Screen par **"locate"** par click karein aur us `.apk` file ko apne phone mein transfer karke install kar lein.

---

## Phone Mein Settings & Permissions:
1. App install karke **Mic permission** allow karein.
2. Screen par **"Enable Phone Control Permission"** button par click karein aur **Accessibility** settings mein jaakar **JARVIS Assistant** ko ON karein.
3. Ab aap jo bhi bolein — WhatsApp messages auto-send honge, reports create honge aur Jarvis aapke phone ke sath communicate karega!
